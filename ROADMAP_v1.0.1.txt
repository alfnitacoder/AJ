AJOS Development Roadmap v1.0.1
================================
Last updated: 2026-01-19

Legend:
  [x] implemented
  [ ] not yet
  [~] partially / in progress

================================================================================
1) Process Management & Multitasking (HIGH PRIORITY - Foundation)
================================================================================
[~] Preemptive scheduler (PIT-driven context switches) [BASIC FRAMEWORK: scheduler_tick, round-robin selection, but no full context switching yet]
[x] Process Control Block (PCB) structure
[~] Process creation/termination syscalls [BASIC: GETPID, GETPPID implemented; fork/exec pending]
[ ] Per-process address spaces (separate page directories)
[ ] Per-process user stacks (separate per program)
[x] Process list command (`ps`) [ENHANCED: shows PPID, CPU time]
[x] Process termination command (`kill <pid>`)
[x] Background jobs (`&` syntax) [BASIC: marks processes as background, but still runs synchronously until full multitasking]
[x] Job control commands (`jobs`, `fg`, `bg`) [BASIC: `jobs` and `wait` implemented, `fg`/`bg` pending full multitasking]
[x] Process state management (RUNNING, SLEEPING, ZOMBIE, etc.)

Why: Enables running multiple programs simultaneously, background tasks, and
     proper isolation between programs. Foundation for pipes, signals, and IPC.

================================================================================
2) TCP Improvements (HIGH PRIORITY - Complete Networking Stack)
================================================================================
[ ] Sliding Window & Flow Control
[~] User-space Socket API (syscalls: socket, bind, listen, accept, connect,
     send, recv, close) [BASIC: All syscalls implemented, but accept needs improvement]
[x] Full HTTP response parsing (not just status line) [BASIC: Parses status code, headers, finds body]
[x] HTTP response body handling [BASIC: Extracts body after headers]
[x] `wget <url>` command - download files via HTTP [BASIC: Downloads and saves to file]
[x] `httpd [port]` command - simple HTTP server [SERVICE: `service httpd start|stop|reload`]
[ ] HTTP POST support
[ ] HTTPS/TLS support (optional, advanced)

Why: Completes the networking stack and enables real applications.

================================================================================
3) Filesystem Enhancements (HIGH PRIORITY - Practical Features)
================================================================================
[ ] File permissions/attributes (read-only flag)
[x] File timestamps (creation/modification time)
[ ] `chmod <mode> <file>` command - change permissions
[x] `touch <file>` command - update timestamp or create empty file
[x] `grep <pattern> <file>` command - search text in files
[ ] File ownership (user/group)
[ ] Symbolic links support

Why: Makes the filesystem more practical and Unix-like.

Current Status Summary
================================================================================

Already Implemented:
- 32-bit protected mode kernel
- IDT + exceptions + IRQs (PIC)
- PIT timer
- Keyboard IRQ + input layer
- Shell + extensive commands (including redirection `>` and `>>`)
- FAT12 read/write with full directory support (mkdir, rm, mv, find)
- Syscalls via int 0x80 (write, ticks, sleep, getkey, exit)
- Ring3 user-mode execution (run3) + TSS stack switch
- Paging (basic identity map)
- Full networking stack (Ethernet, ARP, IPv4, ICMP, UDP, TCP, DHCP, DNS)
- E1000 network driver
- RTC (Real-Time Clock) driver
- Text editor
- PCI scan
- Heap allocator

Partially Implemented:
- User/kernel page protection (partial: only small user window marked user)
- TCP (basic connect/send/recv, but missing sliding window)
- Retransmission (SYN/FIN/small data segments, but not full window)

================================================================================
Recommended Implementation Order
================================================================================

Phase 1 (Foundation):
  1. Process Management & Multitasking (#1)
  2. TCP Improvements (#2) - sliding window, socket API
  3. Filesystem Enhancements (#3) - permissions, timestamps

Phase 2 (Usability):
  4. System Utilities (#4)
  5. Networking Utilities (#5)
  6. Text Processing (#6)

Phase 3 (Advanced):
  7. File Operations (#7)
  8. Advanced Features (#8) - pipes, signals, scripting
  9. Hardware Drivers (#9)
  10. Development Tools (#10)

================================================================================
Notes
================================================================================

- Focus on Phase 1 first to build a solid foundation
- Process management unlocks many other features (pipes, signals, IPC)
- TCP improvements complete the networking stack
- Filesystem enhancements make the OS more practical
- Each phase builds on previous phases
